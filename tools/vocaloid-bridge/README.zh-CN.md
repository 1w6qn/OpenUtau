# OpenUtau VOCALOID 桥接

该分支在 Windows 版 OpenUtau 中增加 VOCALOID 歌手、V5 引擎短句渲染、手动导入声库和实际歌声音高显示。声库和引擎继续使用本机安装文件。

## 使用

1. 启动完整发布目录中的 `OpenUtau.exe`。
2. 选择“文件 → 导入 VOCALOID 声库…”。
3. 选择 V5 引擎安装目录，以及已安装的声库目录。可以选择包含多个声库的根目录。
4. 导入后，歌手列表会自动刷新。选择歌手，输入中文单字或拼音，即可预览。
5. 渲染完成后，钢琴卷帘的“最终音高”显示从实际音频提取的曲线。自动显示不会改写工程；Ctrl+R 可主动将渲染音高载入工程。

重复导入会更新原歌手，保留自定义名称及头尾留白等设置。这里只导入已安装的中文声库，不支持把任意散装 DDB/DDI 文件当成完整安装。导入会在需要时登记普通 V5 声库目录元数据，不复制声库音频，也不迁移授权。

## 本机验证结果

- 6 个 V3/V4/V5 声库均能导入并出现在歌手列表中；重复导入没有新增目录。
- V5 凝、婉、萌三个声库通过实际音频和自动音高测试，包括正负 50 cents 的音高偏移。
- 2 秒测试短句连续渲染 9 次，最慢约 0.44 秒；宿主首次启动约 0.65 秒。速度取决于机器和短句内容。
- V3/V4 三个声库在当前 V5 安装中报告授权数为 0，会显示“待 V5 授权”并明确拒绝渲染。需要先通过厂商流程完成 V5 授权，手动导入不会解除这一限制。

这里的实时预览采用后台完整短句合成和缓存，不是在音频回调中逐采样合成。当前支持普通中文歌唱、音高和 OpenUtau DYN；V5 音高相对当前音符的范围为正负 24 半音。其他语言和未实现的效果参数会明确报错。

旧 V4 后端保留为独立配置选项；默认导入始终使用 V5。旧后端的 V3/V4 出声测试不代表这些声库已能在本机 V5 中渲染。

完整构建和测试命令见 [README.md](README.md)。源码分支为 [codex/vocaloid-v5-bridge](https://github.com/1w6qn/OpenUtau/tree/codex/vocaloid-v5-bridge)。
